# DayTrace

iPhone + Apple Watch 原生、本地优先的个人录音记忆助手。范围以 Auday PRD v0.1 的 D01–D08 为准；使用独立实现，不包含 Auday 原生代码或品牌素材。

**当前状态：开发与验证版本，尚未完成完整日用验收。**

2026-10-15 完成 iPhone SwiftUI 全层级 UI 检查（50 张页面与状态截图）。核心测试 94 通过 / 0 失败；iOS 模拟器测试 9 通过 / 0 失败 / 9 条件跳过；iOS 与 Watch 模拟器构建通过。保留真实 ASR/AI 质量、Watch 物理同步和长时稳定性的验收边界。

仓库只包含源码、测试、项目配置和使用说明；本地设备日志、录音、密钥、临时文件与个人验收记录不会提交。

## 运行

打开 `DayTrace.xcodeproj`，选择 `DayTrace` scheme。最低 iOS 18 / watchOS 11。项目使用 SwiftUI、AVFoundation、WatchConnectivity、Speech、NaturalLanguage、HealthKit、CoreLocation、CryptoKit、CommonCrypto 和 Security，无第三方运行时依赖。实体安装需要自己的开发签名、HealthKit entitlement、开发者模式与配对设备。将 `project.yml` 中的 `DEVELOPMENT_TEAM` 改为自己的团队 ID 后重新生成项目。

修改 `project.yml` 或新增源文件后运行 `xcodegen generate`。不要给包含 Watch 的构建全局指定 iPhone SDK。

## 功能入口

- **Watch**：开始、Mark、暂停/继续、结束、本地待确认队列和连接状态。约 30 秒 AAC 切段；会话序号/结束计数验证完整性，手机持久化 ACK 前不删除音频。事件先于音频到达时可显示 Mark 占位。中断和可检测切段间隔留痕；不保证全天无缝。
- **日记**：日期、24 小时覆盖、小时原文/重点/相关复盘、处理与同步状态、播放器倍速/跳转/逐段高亮。跨午夜按实际时间展示。小时“摘要”复用相关复盘批次，可能覆盖其他小时，界面说明这一边界。
- **自动处理**：在设置独立开启本地自动转写；仅允许端侧 Speech。另行配置 AI 服务、密钥、次数/Token 预约上限并确认自动用途。次日 08:00 后 App 可运行时，每批最多 8 条处理当天全部原文；预算不足保留未完成批次。后台不保证准点，未知付费结果不自动重试。
- **重点和长期记忆**：自动提取分别授权；来源原话验证、自动暂存重放、记忆编辑/停用/冲突/历史/删除。未识别说话人时不把第一人称直接视为用户事实。AI 重点仅收藏后保护音频；Mark 默认前 30/后 60 秒，收藏默认前后各 15 秒，可调整和取消。
- **每日复盘**：按批次展示覆盖进度、全部已完成批次及引用；编辑形成版本，后续自动生成不覆盖用户编辑。手动提前生成仍最多取前 8 条，界面明确标注。分享有编辑和隐藏词预览。
- **搜索/对话**：持久关键词索引和本地句向量，中文复合词/单字低权重匹配、日期范围、来源回跳；模型不可用保留关键词。对话自动选来源并补充生效记忆，发送前显示范围，可取消，历史保留输入快照。语义候选不等于包含答案。
- **健康/位置**：设置中手动读取指定日期的心率、HRV、步数、运动与睡眠日汇总，以及单次大致位置；可按时间回到原文。缺失不填零，不推断压力/情绪。没有后台位置跟踪；本地显示与健康/位置 AI 外发各自独立，外发授权绑定精确接口/模型。
- **存储**：普通原音结束后 30 天到期；仅在转写完成、会话完整、保护范围提取校验完成且未播放时清理。App 可运行时的自动检查可选开启。CAF 保留片段独立可回听，跨文件目前逐段播放；文本不随普通音频到期消失。
- **备份**：设置→加密备份与恢复，至少 12 字符密码；PBKDF2-HMAC-SHA256 600,000 次与 AES-GCM。导入先验证完整性、媒体摘要及关联，再事务替换，失败恢复旧库；拒绝复活本机已删除记录。恢复后自动外发与上下文授权暂停。备份不含 Keychain/密钥，不自动上传；遗失密码无法恢复。
- **实际外发记录**：记录目的服务、模型、时间、文字/记忆/上下文快照与结果状态；先持久化再联网。无原始音频或密钥正文，不跟随重定向。连接测试只发送合成文本，仍可能计费。删除传播到源快照、索引、任务和派生内容。

## 使用顺序

1. 配对真机可用时安装两端；先验证短录音→同步→端侧转写→来源回听。
2. 自行在设置保存完整 HTTPS Chat Completions 接口、模型和密钥；连接测试成功不代表内容质量通过。
3. 检查自动任务用途和预算，再开启自动复盘、记忆、重点。健康和位置需另外确认。
4. 定期主动导出加密备份。目录排除系统备份；长期保留不等于已有备份。
5. 执行真实设备和质量门槛后，才能判断是否适合长期日用。

## 验证

```sh
swift test --build-system native
xcodebuild -project DayTrace.xcodeproj -scheme DayTrace -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build-for-testing
xcodebuild -project DayTrace.xcodeproj -scheme DayTraceWatch -destination 'generic/platform=watchOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

`build-for-testing` 仅编译测试目标，不表示原生测试已执行。2026-10-15 已在 iOS 模拟器运行原生测试：9 项通过；6 项在线/公开语料 opt-in、2 项麦克风权限和1项模拟器中文语义模型不可用的检查跳过。

## 当前边界

本轮 UI 回归使用明确标识的合成数据，没有实际 AI 请求、HealthKit 读取或真实录音。真实设备验收记录保持在本地，仓库没有用截图或构建成功代替日用验收。本地中文向量可用性依系统环境而异：Mac 有 640 维模型，本次 iOS 模拟器不可用，已验证降级显示。测试集为开发用合成材料，不是盲测日用数据。Token 预算是客户端保守预约；未知结果不退额，服务端实际计费和 `max_tokens` 兼容性还需验证。

30 秒 stop/start 可能有间隙；墙钟跳变、锁屏调度、能耗、真实录音时间戳准确性和密集 90 天全量库仍需验收。缺少结束清单/缺段的会话保守保留原件。大库备份和首次索引构建可能占用较长前台时间；未做密集全天数据的 UI 压力验收。
